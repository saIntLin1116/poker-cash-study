# 現金桌學習路徑

這是一個可直接以瀏覽器開啟的靜態課程網站，入口檔案是 `index.html`。不需安裝套件、編譯或伺服器；GitHub Pages 可從 repository 根目錄發布。

## 目前內容

- 8 題程度診斷，依主題弱點調整 10 個課程單元的排序。
- 現金桌課程：位置與有效籌碼、翻前範圍、底池賠率與 EV、SPR、範圍與牌面、轉牌、河牌、詐唬與對手調整、資金與情緒管理、手牌複盤。
- 跟注最低勝率計算器、手牌複盤筆記與單元完成進度。
- 牌譜練習室：手動建立假想情境、計算底池賠率，或以本工具的 `CASH-STUDY-NOTE/1` 自訂 TXT 格式保存／開啟練習筆記。
- 診斷、筆記與進度使用瀏覽器 `localStorage` 儲存在本機。

牌譜練習室只在瀏覽器本機處理自創／虛構練習情境，不會上傳到伺服器；不支援 PokerCraft 或其他平台的匯出檔。使用者應遵守所用撲克平台的牌譜處理與分享規定。

## 教材狀態

製作時專案資料夾沒有現金桌教材，因此課程按常見的 6-max NLHE、約 100bb 有效籌碼作為暫定起點，沒有教材頁碼或章節引用。拿到教材後，應核對術語、範圍表、抽水規則與教材涵蓋範圍，再更新課程內容。診斷分數是概念起點，不足以證明牌桌執行能力或長期勝率。

## 發布到 GitHub Pages

1. 在 repository 的 **Settings → Pages** 選擇從 branch 發布，branch 選 `main`，資料夾選 `/(root)`。
2. Pages 完成建置後，GitHub 會在同一頁顯示網站網址。
