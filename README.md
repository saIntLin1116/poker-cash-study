# 現金桌學習路徑

這是一個可直接以瀏覽器開啟的靜態課程網站，入口檔案是 `index.html`。不需安裝套件、編譯或伺服器；GitHub Pages 可從 repository 根目錄發布。

## 目前內容

- 8 題基礎程度診斷；高分後依玩家自評弱點優先練習，而非把基礎答對當成實戰熟練。
- 個人化主線以 100bb 翻後策略為先：IP 優勢、OOP 過牌、IP check-back、轉牌計畫、河牌抓詐唬，再延伸到 200bb。
- 10 個學習單元含目標、核心觀念、情境題、自我檢查與對應教材書目。
- 100bb 八週可展開課程：每週含整理後重點、自編實戰案例、練習與過關條件；200bb 四週延伸安排附複盤進度檢核。
- 跟注最低勝率計算器、手牌複盤筆記與單元完成進度。
- 牌譜練習室：手動建立假想情境、計算底池賠率，或以本工具的 `CASH-STUDY-NOTE/1` 自訂 TXT 格式保存／開啟練習筆記。
- 診斷、筆記與進度使用瀏覽器 `localStorage` 儲存在本機。

牌譜練習室只在瀏覽器本機處理自創／虛構練習情境，不會上傳到伺服器；不支援 PokerCraft 或其他平台的匯出檔。使用者應遵守所用撲克平台的牌譜處理與分享規定。

## 教材與個人化依據

已盤點 `POKER/教材/OCR/` 內初級、中級與高級現金桌教材，並將主要書目按單元映射。個人化學習路線依基礎診斷與 IP/OOP、check-back、轉牌、河牌抓詐唬等自評弱點安排。診斷分數是概念起點，不足以證明牌桌執行能力或長期勝率。教材年代、遊戲抽水、桌型與玩家池不同，書中範圍表及頻率需視為參考，不能跨情境直接照抄。

## 發布到 GitHub Pages

1. 在 repository 的 **Settings → Pages** 選擇從 branch 發布，branch 選 `main`，資料夾選 `/(root)`。
2. Pages 完成建置後，GitHub 會在同一頁顯示網站網址。
